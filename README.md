# Модуль RNG (Генераторы псевдослучайных чисел и распределений)

> Ответственный: Шаимов Богдан
> Состояние: разработан в ветке `RNG_brench` (v1.2.0), свалидирован автономно
> Проверено по коду: RNG_brenсh2d2f164 | Обновлено: 2026-10-16

## 1. Назначение

Модуль `RNG` отвечает за генерацию псевдослучайных последовательностей и случайных величин с заданными распределениями для симулятора сети LTE. Модуль поддерживает работу с независимыми потоками (`stream_idx` / `stream_offset`) и прогонами (`run_idx`), что обеспечивает побитовую повторяемость экспериментов. Помимо двух математических генераторов (`MRG32k3a` и `Philox4x64`), в модуле реализован режим чтения предзаписанных данных из файлов `.json` и `.csv` (`DataStream`) для прогона симуляции на статических датасетах.

## 2. Границы ответственности

**Делает:**
- Генерирует псевдослучайные числа на полуинтервале $[0.0, 1.0)$ по алгоритмам `MRG32k3a` (`RngStream`, побитово свалидирован с NS-3) и `Philox4x64` (`PhiloxStream`, свалидирован с эталоном в Python).
- Загружает и поочерёдно выдаёт заранее заготовленные числа из файлов `.json` и `.csv` с поддержкой циклического повтора (`DataStream`).
- Предоставляет единый класс-фасад (`RandomGenerator`) для получения случайных величин: равномерного (`uniform`), нормального (`normal`), экспоненциального (`exponential`) и дискретного целочисленного (`get_integer`) распределений, а также для прямого чтения значений из файла в режиме `engine='File'`.
- Управляет независимыми подпотоками внутри одного генератора через смещение `stream_offset` относительно `base_stream_idx`.

**Не делает:**
- Не рассчитывает физику движения абонентов, радиоканал и сетевой трафик (отвечает только за выдачу чисел).
- Не управляет основным циклом симуляции `run_tti` и конфигурацией сценария (это зона ответственности `Simulation Manager`).

## 3. Входы, выходы и зависимости

|                 Вход               |            Откуда                |                                        Формат / смысл                                        |
|------------------------------------|----------------------------------|----------------------------------------------------------------------------------------------|
| `seed`                             | Вызывающий модуль / конфигурация | `int` (по умолчанию `12345`; при `0` заменяется на `12345`) — начальное зерно генератора.    |
| `base_stream_idx`, `stream_offset` | Вызывающий модуль                | `int` — базовый индекс потока и смещение подпотока.                                          |
| `run_idx`                          | Вызывающий модуль                | `int` (по умолчанию `1`) — номер независимого прогона симуляции.                             |
|  `engine  `                        | Вызывающий модуль / конфигурация | `str` (`'MRG32k3a'`, `'Philox'`, `'File'`) — выбор алгоритма генерации или файлового режима. |
| `filepath`                         | Вызывающий модуль / конфигурация | `str | None` — путь к файлу `.json` или `.csv` (обязателен при `engine='File'`).             |
| Параметры распределений            | Вызывающий модуль                | `min_val`, `max_val`, `mean`, `variance`, `bound` (`float` / `int`).                         |

|               Выход                       |                  Куда                                   |                              Формат / смысл                                               |
|-------------------------------------------|---------------------------------------------------------|-------------------------------------------------------------------------------------------|
| Базовое число $U(0, 1)$                   | Внутри `RandomGenerator` / в тесты                      | `float` в диапазоне $[0.0, 1.0)$ из `RngStream.rand_u01()` или `PhiloxStream.rand_u01()`. |
| Случайная величина / значение из датасета | Вызывающий модуль (тесты, `Simulation Manager`, модели) | `float` (`uniform`, `normal`, `exponential`) или `int` (`get_integer`).                   |

**Зависимости:**
- Только стандартная библиотека Python 3.12 (`math`, `csv`, `json`, `os`, `collections.deque`).
- Внешних зависимостей от других модулей проекта нет.

## 4. Как проверить работу

Модуль запускается и проверяется полностью автономно из командной строки:

` ` `bash
python3 -c "
from RNG import RandomGenerator

rng_mrg = RandomGenerator(seed=12345, base_stream_idx=0, run_idx=1, engine='MRG32k3a')
print('MRG32k3a uniform:', [round(rng_mrg.uniform(0.0, 1.0, stream_offset=0), 6) for _ in range(3)])

rng_phi = RandomGenerator(seed=12345, base_stream_idx=0, run_idx=1, engine='Philox')
print('Philox normal:', [round(rng_phi.normal(mean=0.0, variance=1.0, stream_offset=1), 6) for _ in range(3)])
"
` ` `
**Ожидаемый результат:**
- Повторные запуски с теми же параметрами `(seed, base_stream_idx, run_idx, stream_offset)` возвращают полностью идентичные последовательности чисел.

## 5. Основные компоненты

|          Файл / класс / функция       | Назначение | Где используется |
|---------------------------------------|---|---|
| `RNG.py::RngStream`                   | Математическое ядро генератора `MRG32k3a` с предвычислением матриц перехода для сдвига по потокам и прогонам. | Внутри `RandomGenerator._get_stream` (по умолчанию) и в тестах валидации с NS-3. |
| `RNG.py::RngStream.rand_u01`          | Генерирует очередное псевдослучайное число на интервале $(0, 1)$.                                             | Методы распределений `RandomGenerator`. |
| `RNG.py::PhiloxStream`                | Математическое ядро 64-битного генератора `Philox4x64` (10 раундов, буфер на 4 числа).                        | Внутри `RandomGenerator._get_stream` при `engine='Philox'`. |
| `RNG.py::PhiloxStream.rand_u01`       | Извлекает число из буфера и нормализует его к $[0.0, 1.0)$ делением на $2^{64}$.                              | Методы распределений `RandomGenerator` при `engine='Philox'`. |
| `RNG.py::DataStream`                  | Считывает числовые последовательности из `.json` или `.csv` в очередь `deque` с поддержкой циклического чтения (`loop=True`). | Внутри `RandomGenerator._get_stream` при `engine='File'`. |
| `RNG.py::DataStream.get_next_value`   | Возвращает следующее число из буфера файла (при `loop=True` перезаполняет буфер после исчерпания). | Методы `RandomGenerator` при `engine='File'`. |
| `RNG.py::RandomGenerator`             | Единая точка входа для генерации распределений и управления словарём потоков `_streams`. | Тестовые сценарии; при интеграции — `Simulation Manager` и модели. |
| `RNG.py::RandomGenerator.uniform`     | Равномерное распределение на $[min\_val, max\_val)$ (в режиме `'File'` возвращает следующее готовое число из файла). | Внешние вызовы и метод `get_integer`. |
| `RNG.py::RandomGenerator.normal`      | Нормальное распределение (полярный метод Бокса — Мюллера с кэшированием второго числа в `_normal_cache` и усечением `bound`). | Генерация гауссовских величин. |
| `RNG.py::RandomGenerator.exponential` | Экспоненциальное распределение методом обратного преобразования с потолком `bound`. | Генерация экспоненциальных величин (интервалы). |
| `RNG.py::RandomGenerator.get_integer` | Генерация целого числа в диапазоне $[min\_val, max\_val]$ включительно. | Выбор целочисленных параметров и индексов. |

## 6. Один типичный сценарий

**Сценарий: Получение случайных величин в математическом и файловом режимах**
1. Вызывающий код создаёт `rng = RandomGenerator(seed=12345, base_stream_idx=0, run_idx=1, engine='MRG32k3a')`.
2. При вызове `rng.normal(mean=0.0, variance=1.0, bound=3.0, stream_offset=1)` метод `_get_stream(1)` лениво инициализирует поток `RngStream(seed=12345, stream_idx=1, run_idx=1)` и сохраняет его в `self._streams[1]`.
3. Метод `normal()` запрашивает два числа через `rand_u01()`, вычисляет пару нормальных величин по методу Бокса — Мюллера, сохраняет вторую величину в `self._normal_cache[1]` для следующего обращения и возвращает первую.
4. Если `RandomGenerator` инициализирован с `engine='File'` и путём `filepath='data.csv'`, вызов `rng.uniform()` обращается к `DataStream.get_next_value()` и возвращает готовое значение напрямую из файла без математического пересчёта.
