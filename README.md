## 1. Назначение

Модуль `RNG` отвечает за генерацию псевдослучайных последовательностей и случайных величин с заданными распределениями для симулятора сети LTE. Модуль поддерживает работу с независимыми потоками (`stream_idx` / `stream_offset`) и прогонами (`run_idx`), что обеспечивает побитовую повторяемость экспериментов. Помимо двух математических генераторов (`MRG32k3a` и `Philox4x64`), в модуле реализован режим чтения предзаписанных данных из файлов `.json` и `.csv` (`DataStream`) для прогона симуляции на статических датасетах.

## 2. Границы ответственности

**Делает:**
- Генерирует псевдослучайные числа на полуинтервале $[0.0, 1.0)$ по алгоритмам `MRG32k3a` (`RngStream`, побитово свалидирован с NS-3) и `Philox4x64` (`PhiloxStream`, свалидирован с эталоном в Python).
- Загружает и поочерёдно выдаёт заранее заготовленные числа из файлов `.json` и `.csv` с поддержкой циклического повтора (`DataStream`).
- Предоставляет единый класс-фасад (`RandomGenerator`) для получения случайных величин: равномерного (`uniform`), нормального (`normal`), экспоненциального (`exponential`) и дискретного целочисленного (`get_integer`) распределений, а также для прямого чтения значений из файла в режиме `engine='File'`.
- Управляет независимыми подпотоками внутри одного генератора через смещение `stream_offset` относительно `base_stream_idx`.

**Не делает:**
- Не рассчитывает физику движения абонентов, радиоканал и сетевой трафик (отвечает только за выдачу чисел).
- Не управляет основным циклом симуляции `run_tti` и конфигурацией сценария (это зона ответственности `Simulation Manager`).

## 3. Входы, выходы и зависимости

|                 Вход               |            Откуда                |                                        Формат / смысл                                        |
|------------------------------------|----------------------------------|----------------------------------------------------------------------------------------------|
| `seed`                             | Вызывающий модуль / конфигурация | `int` (по умолчанию `12345`; при `0` заменяется на `12345`) — начальное зерно генератора.    |
| `base_stream_idx`, `stream_offset` | Вызывающий модуль                | `int` — базовый индекс потока и смещение подпотока.                                          |
| `run_idx`                          | Вызывающий модуль                | `int` (по умолчанию `1`) — номер независимого прогона симуляции.                             |
|  `engine  `                        | Вызывающий модуль / конфигурация | `str` (`'MRG32k3a'`, `'Philox'`, `'File'`) — выбор алгоритма генерации или файлового режима. |
| `filepath`                         | Вызывающий модуль / конфигурация | `str | None` — путь к файлу `.json` или `.csv` (обязателен при `engine='File'`).             |
| Параметры распределений            | Вызывающий модуль                | `min_val`, `max_val`, `mean`, `variance`, `bound` (`float` / `int`).                         |

|               Выход                       |                  Куда                                   |                              Формат / смысл                                               |
|-------------------------------------------|---------------------------------------------------------|-------------------------------------------------------------------------------------------|
| Базовое число $U(0, 1)$                   | Внутри `RandomGenerator` / в тесты                      | `float` в диапазоне $[0.0, 1.0)$ из `RngStream.rand_u01()` или `PhiloxStream.rand_u01()`. |
| Случайная величина / значение из датасета | Вызывающий модуль (тесты, `Simulation Manager`, модели) | `float` (`uniform`, `normal`, `exponential`) или `int` (`get_integer`).                   |

**Зависимости:**
- Только стандартная библиотека Python 3.12 (`math`, `csv`, `json`, `os`, `collections.deque`).
- Внешних зависимостей от других модулей проекта нет.

## 4. Как проверить работу

Модуль запускается и проверяется полностью автономно из командной строки:

` ` `bash
python3 -c "
from RNG import RandomGenerator

rng_mrg = RandomGenerator(seed=12345, base_stream_idx=0, run_idx=1, engine='MRG32k3a')
print('MRG32k3a uniform:', [round(rng_mrg.uniform(0.0, 1.0, stream_offset=0), 6) for _ in range(3)])

rng_phi = RandomGenerator(seed=12345, base_stream_idx=0, run_idx=1, engine='Philox')
print('Philox normal:', [round(rng_phi.normal(mean=0.0, variance=1.0, stream_offset=1), 6) for _ in range(3)])
"
` ` `
