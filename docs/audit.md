## 2. Карточки критических дефектов (по итогам ревью)

### BUG-RNG-001: Искажение распределения через `int()` в `get_integer`
- **Объект:** `RandomGenerator.get_integer`
- **Наблюдение:** Использование `int()` отбрасывает дробную часть к нулю. На отрицательных диапазонах (например, `[-5, 5]`) это смещает вероятности: ноль выпадает в 2 раза чаще, а левая граница почти никогда.
- **Решение:** Заменить `int(...)` на `math.floor(...)`.

### BUG-RNG-002: Уязвимость к бесконечному циклу при отрицательном `bound`
- **Объект:** `RandomGenerator.normal` и `exponential`
- **Наблюдение:** Нет проверки `bound >= 0`. При передаче отрицательного `bound` математическое условие выхода из цикла `abs(...) <= bound` становится невыполнимым (Deadlock).
- **Решение:** Добавить Guard Clause `if bound < 0: raise ValueError(...)`.

### BUG-RNG-003 (P0): Для `File` все offsets читают один файл с начала
- **Объект:** `RandomGenerator._get_stream`, `DataStream`
- **Наблюдение:** При `engine='File'` для каждого `stream_offset` создаётся новый экземпляр `DataStream`, который читает один и тот же файл с первой строки. Нарушается контракт независимости потоков.
- **Решение:** Вынести работу с датасетами из математического фасада PRNG.

### BUG-RNG-004: Потеря точности Philox (возврат 1.0)
- **Объект:** `PhiloxStream.rand_u01`
- **Наблюдение:** Деление 64-битного `integer` на $2^{64}$ с округлением во `float` (53 бита точности) в исключительных случаях может вернуть `1.0`, нарушая полуинтервал $[0.0, 1.0)$.
- **Решение:** Использовать битовый сдвиг: `(val >> 11) * 0x1.0p-53`.

### BUG-RNG-005: Неизвестный `engine` попадает в ветку `else`
- **Объект:** `RandomGenerator._get_stream`
- **Наблюдение:** При опечатке в названии движка (например, `engine='phlox'`) код молча попадает в ветку `else` и запускает `MRG32k3a`.
- **Решение:** Добавить строгую валидацию по реестру стратегий и выбрасывать `ValueError`.

### BUG-RNG-006: Отрицательный `stream_idx` преобразуется в общий старт
- **Объект:** `RngStream.__init__`
- **Наблюдение:** Любые отрицательные индексы схлопываются в `0`. Несколько разных источников получат одинаковую последовательность.
- **Решение:** Добавить валидацию `if stream_idx < 0: raise ValueError(...)`.
